# Fathalla_Market_Project

Project: Fathalla Market Sales Analysis

This repository contains the prepared data, analysis scripts, and Power BI artifacts for the Fathalla Market project.

## Structure
- `data/raw/` - original raw CSV files (backup, not modified)
- `data/clean/` - cleaned and processed files ready for analysis
- `notebooks/` - Jupyter notebooks for EDA and feature engineering
- `src/` - Python scripts for ETL and utilities
- `excel/` - Excel files used for initial cleaning and templates
- `powerbi/` - Power BI (.pbix) files and exported reports
- `reports/` - final slides and PDF reports
- `docs/` - documentation and notes
- `outputs/` - exported images, tables, and intermediate files

## Quick start
1. Put your raw CSV in `data/raw/`
2. Run the ETL script in `src/` or the notebooks in `notebooks/`
3. Open `Fathalla_Market_Project.pbix` in Power BI (saved in `powerbi/`) after preparing `data/clean/`
